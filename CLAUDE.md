# nicookie

Fork of `@steipete/sweet-cookie` (Steipete, MIT). Node >=22 or Bun; Bun
workspace. The CLI entrypoint builds to `packages/core/dist/cli.js`.

After changes run the narrow checks: `bun run check`, `bun run test`,
`bun run test:bun`, `bun run lint`, `bun run build`. Use `bun run` for these:
bare `bun test` and `bun build` are Bun's own test runner and bundler.
